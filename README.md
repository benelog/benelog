### 🛠 도구

명령 하나로 실행되는, 설치와 설정이 필요 없는 프로그램들.

- **[one-ftpserver](https://github.com/benelog/one-ftpserver)** `Go` — 설정 파일 없이 명령 한 줄로 뜨는 FTP 서버. 모든 설정이 플래그라서 `--help`가 곧 전체 레퍼런스이고, FTPS도 `--ssl` 하나면 인증서를 메모리에 만들어 붙인다.
- **[uploader](https://github.com/benelog/uploader)** `Go` — 브라우저로 서버에 파일을 올리는 단일 바이너리 웹 앱. SSH를 쓸 수 없는 상황에서 목적지 디렉터리와 파일만 고르면 되고, 업로드는 디스크로 스트리밍되어 파일 크기에 제약이 없다.
- **[md-lens](https://github.com/benelog/md-lens)** `Go` — 터미널용 마크다운 뷰어(`mdl`). 코드 문법 강조, 인라인 이미지, 큰 글씨 제목까지 렌더링한다.
- **[pdf-refinery](https://github.com/benelog/pdf-refinery)** `Python` — 스캔한 책 PDF를 검색 가능한 문서로 바꾸는 CLI. [PaddleOCR](https://github.com/PaddlePaddle/PaddleOCR)로 읽은 텍스트를 보이지 않는 레이어로 덧입혀 원본 모양은 그대로 두고 검색·복사만 가능하게 만든다.
- **[obsidian-site](https://github.com/benelog/obsidian-site)** `TypeScript` — Obsidian 볼트를 정적 사이트로 만드는 생성기. 위키링크 이동, 자동 백링크, 링크 그래프를 함께 만들어 준다. 바로 시작하려면 [obsidian-site-template](https://github.com/benelog/obsidian-site-template).
- **[dumper](https://github.com/benelog/dumper)** `Java` — 웹 브라우저로 자바 스택 덤프를 받아 가는 웹 애플리케이션.
- **[shell-proxy](https://github.com/benelog/shell-proxy)** `Java` — URL 호출로 서버의 셸 명령을 실행하는 프록시 서버.

### 📚 예제와 정리

글이나 발표에 딸려 쓰이는, 읽으라고 만든 코드들.

- **[java-concurrency](https://github.com/benelog/java-concurrency)** `Java` — 자바 동시성 API를 주제별로 정리한 예제 모음.
- **[spring-jdbc-tips](https://github.com/benelog/spring-jdbc-tips)** `Java` — Spring JDBC 활용 팁과 SQL 관리 방안.
- **[multiline](https://github.com/benelog/multiline)** `Java` — Javadoc 주석을 이용해 자바에 멀티라인 문자열 리터럴을 구현한 애노테이션 프로세서.
- **[lambda-resort](https://github.com/benelog/lambda-resort)** `Java` — 필터·정렬·매핑을 Java, Groovy, Scala, Kotlin, Xtend, Ceylon으로 각각 작성해 비교한 예제.
- **[h2demo](https://github.com/benelog/h2demo)** `Java` — HTTP/2의 효과를 눈으로 확인하는 데모.
- **[egloos-migration](https://github.com/benelog/egloos-migration)** `Kotlin` — 이글루스 블로그를 다른 곳으로 옮기기 위한 마이그레이션 도구.
